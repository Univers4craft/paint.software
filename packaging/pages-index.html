paint.software

Open-source Paint.NET clone for Linux — APT repository

Install via APT (Debian / Ubuntu / Linux Mint)

Add the repository once, then install and get updates like any other package:

echo "deb [trusted=yes] https://univers4craft.github.io/paint.software stable main" \
  | sudo tee /etc/apt/sources.list.d/paint.software.list
sudo apt update
sudo apt install paint.software

Updates then come automatically with sudo apt update && sudo apt upgrade.

Or install a single .deb

Download the latest .deb from the Releases page, then:

sudo apt install ./paint.software_*_amd64.deb

Note: this repository is currently unsigned, hence [trusted=yes]. The project is at github.com/Univers4craft/paint.software.
